# 🐍 Lista de Exercícios — Revisão de Python

Esta lista tem como objetivo revisar os principais conceitos básicos de Python.

As questões combinam **interpretação de código, identificação de erros e implementação de pequenos programas**.

## 📚 Conteúdos

A lista está organizada em 11 tópicos:

1. Olá, Mundo!
2. Variáveis e Tipos
3. Listas
4. Operadores Básicos
5. Formatação de Strings
6. Operações Básicas com Strings
7. Condições
8. Loops
9. Funções
10. Dicionários
11. Entrada e Saída

Ao todo, são **33 questões**.

## ▶️ Executando os exercícios

Para executar um programa Python no terminal:

```bash
python nome-do-arquivo.py
```

Por exemplo:

```bash
python 01-ola-mundo.py
```

## 💡 Dica

Tente resolver as questões **sem executar o código primeiro** sempre que a questão pedir para determinar uma saída.

Depois, use o Python para verificar sua resposta.
